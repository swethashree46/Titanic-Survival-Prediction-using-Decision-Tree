Project Overview

This project predicts the survival of Titanic passengers based on their age and passenger class (Pclass) using a Decision Tree Classifier. The dataset provides historical insights into the Titanic disaster, allowing us to analyze patterns in survival probability.

Objectives

✅ Predict passenger survival using Decision Tree Classifier✅ Identify key survival factors such as age and class✅ Evaluate model accuracy and performance metrics

Technologies & Tools Used

Python 🐍

Pandas 📊

Scikit-learn 🤖

Decision Tree Classifier 🌳

Jupyter Notebook 📝

Implementation Steps

1️⃣ Data Preprocessing:

Load Titanic dataset

Handle missing values

Extract relevant features: Age and Pclass

2️⃣ Model Building:

Train a Decision Tree Classifier to classify survival (0 = No, 1 = Yes)

Visualize decision boundaries for interpretability

3️⃣ Evaluation & Prediction:

Test model accuracy using evaluation metrics

Identify survival patterns in different passenger classes

Insights & Learnings

🔹 Passenger Class (Pclass) plays a crucial role in survival probability🔹 Younger passengers had a higher survival rate🔹 Decision Trees effectively classify survival outcomes with simple rules
